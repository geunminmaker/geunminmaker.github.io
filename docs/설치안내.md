# 조각조각 설치 안내

조각조각은 인터넷 주소로 여는 앱입니다. 주소를 한 번 열어 홈 화면에 추가하면, 그다음부터는 다른 앱처럼 아이콘을 눌러 씁니다.

**주소: https://geunminmaker.github.io/split-image/**

- 설치하지 않고 주소만 열어도 똑같이 쓸 수 있습니다.
- 처음 열 때 약 15MB를 내려받습니다. 와이파이에서 여는 것을 권합니다.
- 고른 사진과 문서는 휴대폰 안에서만 처리됩니다. 어디에도 전송되지 않습니다.

---

## iPhone · iPad

iPhone에는 설치 파일이 따로 없습니다. Safari에서 홈 화면에 추가하는 것이 설치입니다.

1. **Safari**로 위 주소를 엽니다.
   카카오톡이나 문자에서 링크를 눌렀다면, 화면 안내에 따라 Safari로 다시 엽니다. 카카오톡 안에서는 설치와 저장이 되지 않습니다.
2. 화면 아래의 **공유 버튼**(네모에서 화살표가 위로 나가는 모양)을 누릅니다.
   공유 버튼이 안 보이면 아래쪽 **···** 버튼을 먼저 누르고 **공유**를 누릅니다.
3. 목록을 조금 내려 **홈 화면에 추가**를 누릅니다.
4. 오른쪽 위 **추가**를 누릅니다. "웹 앱으로 열기"가 보이면 켠 채로 둡니다.
5. 홈 화면에 생긴 **조각조각** 아이콘을 누릅니다.

알아 둘 점

- 홈 화면 앱을 처음 열 때 준비 파일을 한 번 더 내려받습니다. Safari와 홈 화면 앱은 저장 공간을 따로 쓰기 때문입니다.
- 앱 안의 **앱 설치** 버튼을 눌러도 같은 순서를 그림과 함께 보여 줍니다.

### iPhone에서 결과 저장하기

**저장하기**를 누르면 공유 창이 열립니다.

| 하고 싶은 것 | 공유 창에서 고를 것 |
| --- | --- |
| 파일 앱에 보관 | 파일에 저장 |
| 사진 앱에 넣기 (JPG·PNG) | 이미지 저장 |
| 바로 인쇄 | 프린트 |
| 다른 사람에게 보내기 | 카카오톡, 메일 등 |

## Android

방법이 두 가지 있습니다. **방법 1을 권합니다.** 더 쉽고 경고 창이 뜨지 않습니다.

### 방법 1. Chrome에서 설치 (권장)

1. **Chrome**으로 위 주소를 엽니다. 삼성 인터넷도 됩니다.
2. 화면 오른쪽 위 **앱 설치**를 누르고, 이어서 **앱 설치하기**를 누릅니다.
3. 설치 창에서 **설치**를 누릅니다.
4. 홈 화면이나 앱 서랍에 생긴 **조각조각** 아이콘을 누릅니다.

설치 창이 뜨지 않으면 Chrome 오른쪽 위 **⋮** 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 고릅니다.

### 방법 2. 설치 파일(APK)로 설치

설치 파일이 꼭 필요할 때만 쓰십시오. Play 스토어에 올린 앱이 아니어서 휴대폰이 경고를 보여 줍니다.

1. 아래 주소에서 `jogakjogak.apk`를 내려받습니다.
   https://github.com/geunminmaker/geunminmaker.github.io/releases/latest/download/jogakjogak.apk
2. 내려받은 파일을 엽니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정**을 누르고, **이 출처 허용**을 켠 뒤 뒤로 돌아옵니다.
4. **설치**를 누릅니다.

삼성 Galaxy에서 "보안 위험 자동 차단" 때문에 설치가 막히면 방법 1을 쓰십시오. 방법 1은 이 설정과 상관없이 됩니다.

알아 둘 점

- 이 앱은 Chrome을 이용해 화면을 보여 줍니다. Chrome이 설치되어 있어야 합니다.
- 인터넷 주소로 여는 앱과 내용이 같습니다. 새 버전도 같이 받습니다.

### Android에서 결과 저장하기

**저장하기**를 누르면 **다운로드** 폴더에 저장됩니다. "내 파일" 앱의 다운로드에서 찾을 수 있습니다.

- PDF · Word · PowerPoint · 한글: 파일 하나로 저장됩니다.
- JPG · PNG: 조각 여러 장이 ZIP 파일 하나로 묶여 저장됩니다. 파일을 눌러 압축을 풀면 됩니다.
- PDF · JPG · PNG는 **공유** 버튼으로 카카오톡 등에 바로 보낼 수 있습니다. 조각이 10장보다 많은 이미지와 Word · PowerPoint · 한글 파일은 저장한 뒤에 보내십시오.

## PC (Windows · Mac)

Chrome이나 Edge로 주소를 열면 주소창 오른쪽에 설치 아이콘이 나타납니다. 누르면 창이 따로 뜨는 앱으로 설치됩니다. 설치하지 않고 브라우저에서 그대로 써도 됩니다.

---

## 인쇄할 때

- 조각을 종이에 한 장씩 뽑으려면 **PDF**로 저장하는 것이 가장 편합니다. 한 쪽에 조각이 하나씩 들어갑니다.
- 용지 크기에서 **A4**를 고르면 A4 한 장에 맞게 여백을 두고 들어갑니다.
- 인쇄 창에서 "용지에 맞춤"을 고르면 조각이 종이에 꽉 차게 나옵니다.

## 자주 묻는 것

**인터넷이 없어도 되나요?**
한 번 열어서 준비가 끝난 뒤에는 인터넷 없이도 열립니다. PDF·한글·Office 문서를 처음 열 때는 추가 파일(약 18MB)을 한 번 더 받습니다.

**새 버전은 어떻게 받나요?**
앱을 열 때 자동으로 확인합니다. 첫 화면에 새 버전 안내가 보이면 누르십시오.

**지우려면요?**
다른 앱과 똑같이 아이콘을 길게 눌러 삭제합니다.

**"앱 설치" 버튼이 안 보여요.**
이미 설치했거나, 카카오톡·인스타그램 같은 앱 안에서 연 경우입니다. Safari나 Chrome에서 주소를 직접 여십시오.

**파일이 열리지 않아요.**
암호가 걸린 문서는 암호를 물어봅니다. 배포용(읽기 전용) 한글 문서와 손상된 파일은 열 수 없습니다. 그럴 때는 화면을 캡처한 사진을 넣으면 됩니다.
